# Spell Lab for Clash Royale 2.1306.1

Open Settings → Mod Lab → Spells on a settled home screen. Select a spell, enable the editor, change a field and tap Apply. Closing discards pending edits. Apply with the editor switched off to restore game behavior while keeping the chosen values for later. The existing Phone Photos Hydrogen build can run this guest. Keep the same guest instance and Documents directory when updating.

| Spell | Editable fields |
| --- | --- |
| Fireball, Arrows, Rocket | Projectile damage, radius, speed, elixir |
| Goblin Barrel | Radius, speed, elixir |
| Rage | Radius, duration, elixir |
| Freeze, Zap | Radius, elixir |
| Lightning | Projectile damage, radius, duration, speed, elixir |
| Mirror | None. Cost and copied behavior are determined at play time. |

The catalog derives stable IDs from the pinned spell table and resolves primary, first-shot and area projectiles. Apply restores the original cached values before composing each set of overrides. An explicit spell override takes precedence over a unit or spawn override. A percentage of 100 or cost Default leaves the other editor in control. Spells that share a projectile object can share the effect. Training and friendly battles use original values. Rage duration changes the area's lifetime, preserving the refresh interval. Changing Lightning's duration can affect the number of strikes.

## Persistence

Documents/ClashSpellLab-v1.bin is optional. Its SLP1 header contains seven little-endian 32-bit words for magic, version, record count, enabled flag, selection, body checksum and header checksum. Each record contains the stable spell ID followed by damage, radius, duration, speed and cost. The reader checks size, checksums, IDs, supported fields and ranges. Missing profiles default to disabled. Invalid files remain available for diagnosis. Explicit Reset and Apply archives a rejected file and refuses to overwrite a previous rejection archive. Successful saves flush and rename a temporary file. Older saves and Forge definitions keep their existing formats.
