# GL entry points forwarded by the host GL backend (src/runtime/gl).
# Format: <ret> <name>(<type> <arg>, ...)   types:
#   E enum/uint32  U uint  BF bitfield  I int  S sizei  B boolean  F float
#   IP intptr  SP sizeiptr  p const pointer in  w pointer out  cs const char*
#   Y GLsync  L uint64  (returns: P void*, Y GLsync, cs string; '!' rows only)
#   o vertex-array pointer or offset (GL_ARRAY_BUFFER)  e index pointer or offset (GL_ELEMENT_ARRAY_BUFFER)
# Lines starting with '!' are declared in the table but wrapped by hand (HostGL.cpp).
# Suffix [es1] / [es2] limits registration to that API family (both by default).
